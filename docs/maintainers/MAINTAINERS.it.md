# Condividi la pagina della tua comunità

Se una comunità è inclusa in Openings, la sua pagina raccoglie le offerte pubbliche indicizzate dal relativo repository GitHub. Ogni annuncio mantiene il link alla fonte originale.

Openings non modifica le pubblicazioni della comunità, non riceve candidature e non accede a repository privati o dati delle candidature.

## URL della comunità

Sostituisci `OWNER/REPO` con il nome del repository su GitHub:

```txt
https://openings.dev/communities/OWNER/REPO
```

Esempio:

```txt
https://openings.dev/communities/qa-brasil/vagas
```

Controlla che la pagina esista prima di condividerla.

## Link per il README

```md
[Vedi le offerte di questa comunità su openings.dev](https://openings.dev/communities/OWNER/REPO)
```

## Badge per il README

```md
[![Offerte aperte su openings.dev](https://img.shields.io/badge/openings.dev-open_jobs-111827?logo=github)](https://openings.dev/communities/OWNER/REPO)
```

## Messaggio breve

```md
Consulta le offerte aperte di questa comunità su openings.dev:
https://openings.dev/communities/OWNER/REPO

Openings facilita la ricerca degli annunci pubblici della comunità e mantiene il link alla fonte originale di ogni offerta.
```

## Correzione o rimozione

Per correggere le informazioni di una comunità o chiedere la rimozione della sua pagina, usa il modulo pubblico e indica il link interessato e la modifica richiesta. Se la richiesta non deve essere pubblica, scrivi a `support@openings.dev`.

```txt
https://github.com/openings-dev/openings/issues/new?template=content_correction.yml
```
