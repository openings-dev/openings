# Per maintainer

openings.dev offre una vista pubblica piu chiara per le offerte che la tua community pubblica gia come issue su GitHub. Non sostituisce il repository, non modifica le issue, non riceve candidature e non archivia dati privati.

Usa il modello di URL qui sotto e sostituisci `OWNER/REPO` con il nome del repository GitHub:

```txt
https://openings.dev/community/OWNER/REPO
```

Esempio:

```txt
https://openings.dev/community/qa-brasil/vagas
```

## Link per il README

```md
[Vedi le offerte di questa community su openings.dev](https://openings.dev/community/OWNER/REPO)
```

```md
[![Offerte su openings.dev](https://img.shields.io/badge/openings.dev-vedi_offerte-111827?logo=github)](https://openings.dev/community/OWNER/REPO)
```

## Messaggio breve suggerito

```md
Abbiamo aggiunto una vista openings.dev per questa community:
https://openings.dev/community/OWNER/REPO

Indicizza le issue pubbliche con offerte da questo repository e rende piu semplice cercare, filtrare e condividere. Le issue originali su GitHub restano la fonte ufficiale.
```

## Correzioni o rimozione

Se la community vuole correggere o rimuovere la scheda, apri una issue nel repository di openings.dev:

```txt
https://github.com/openings-dev/openings/issues/new
```
