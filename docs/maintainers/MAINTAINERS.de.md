# Für Maintainer

openings.dev bietet eine klarere öffentliche Ansicht für Jobs, die eure Community bereits als GitHub-Issues veröffentlicht. Es ersetzt das Repository nicht, bearbeitet keine Issues, nimmt keine Bewerbungen an und speichert keine privaten Daten.

Verwende das folgende URL-Muster und ersetze `OWNER/REPO` durch den Namen des GitHub-Repositorys:

```txt
https://openings.dev/community/OWNER/REPO
```

Beispiel:

```txt
https://openings.dev/community/qa-brasil/vagas
```

## Kurze Nachricht

```md
Wir haben eine openings.dev-Ansicht für diese Community ergänzt:
https://openings.dev/community/OWNER/REPO

Sie indexiert die öffentlichen Job-Issues aus diesem Repository und macht Suche, Filter und Teilen einfacher. Die originalen GitHub-Issues bleiben die offizielle Quelle.
```

## Korrektur oder Entfernung

Wenn die Community den Eintrag korrigieren oder entfernen möchte, öffne eine Issue im openings.dev-Repository:

```txt
https://github.com/openings-dev/openings/issues/new
```
