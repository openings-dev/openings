# Divulgue a página da sua comunidade no Openings

O openings.dev facilita a busca e o compartilhamento de anúncios públicos de vagas publicados em repositórios de comunidades compatíveis no GitHub. Ele não substitui o repositório, não edita anúncios, não recebe candidaturas e não acessa repositórios privados ou dados de candidaturas.

Use o padrão de URL abaixo e substitua `OWNER/REPO` pelo nome do seu repositório no GitHub:

```txt
https://openings.dev/community/OWNER/REPO
```

Por exemplo:

```txt
https://openings.dev/community/qa-brasil/vagas
```

## Link no README

```md
[Ver as vagas desta comunidade no openings.dev](https://openings.dev/community/OWNER/REPO)
```

## Sugestão de mensagem curta

```md
Os anúncios públicos de vagas desta comunidade estão mais fáceis de consultar no openings.dev:
https://openings.dev/community/OWNER/REPO

A página facilita a busca, a filtragem e o compartilhamento desses anúncios. Cada resultado mantém o link para a fonte original, onde estão os detalhes atuais e os próximos passos.
```

## Correções ou remoção

Para pedir uma correção ou remoção, use o formulário público específico. Se o pedido não puder ser público, escreva para `support@openings.dev`.

```txt
https://github.com/openings-dev/openings/issues/new?template=content_correction.yml
```
