# Para mantenedores

O openings.dev oferece uma visualização pública mais limpa para as vagas que a sua comunidade já publica como issues no GitHub. Ele não substitui o repositório, não edita issues, não recebe candidaturas e não armazena dados privados.

Use o padrão de URL abaixo e troque `OWNER/REPO` pelo nome do repositório no GitHub:

```txt
https://openings.dev/community/OWNER/REPO
```

Exemplo:

```txt
https://openings.dev/community/qa-brasil/vagas
```

## Link para o README

```md
[Ver vagas desta comunidade no openings.dev](https://openings.dev/community/OWNER/REPO)
```

## Mensagem curta sugerida

```md
Adicionamos uma visualização no openings.dev para esta comunidade:
https://openings.dev/community/OWNER/REPO

Ela indexa as issues públicas de vagas deste repositório e facilita busca, filtros e compartilhamento. As issues originais no GitHub continuam sendo a fonte oficial.
```

## Correções ou remoção

Se a comunidade quiser ajustar ou remover a listagem, abra uma issue no repositório do openings.dev:

```txt
https://github.com/openings-dev/openings/issues/new
```
