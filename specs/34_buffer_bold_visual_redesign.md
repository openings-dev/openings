# 34 — Buffer Bold visual redesign

Status: Complete

## Approved direction

Replace Calm Professional with a Buffer-inspired bold editorial system adapted to Openings. Do not reproduce Buffer logos, illustrations, copy, or product-specific layouts.

- Warm cream canvas and white content surfaces.
- Warm near-black text, borders, and offset shadows.
- Soft Grape `#7650B8` as the primary signature color.
- Pale lavender, peach, yellow, green, and blue accents used sparingly.
- Bold rounded display typography, sentence case, generous line height, and friendly shapes.
- Two-pixel borders on primary containers and controls; offset hard shadows on interactive or important surfaces.
- Reduced translucency, blur, and ambient gradients.
- Full-width opportunity results with no persistent filter sidebar.
- Search, location, and stack remain in the quick action bar.
- Advanced filters open in an accessible modal on desktop and near-full-screen dialog on mobile.

## Product constraints

Preserve routes, query keys, remote data, locale coverage, themes, opportunity ordering, drawer behavior, and static export. Dark mode translates the same visual grammar instead of becoming a different system.

## Approval evidence

The user selected the bold outlined Buffer direction, changed the primary accent from Buffer blue to Soft Grape, and approved replacing the filter sidebar with the advanced-filter modal.
